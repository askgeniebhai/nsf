# NSF — Instructions for AI Coding Agents

Before making **any** change to this repository, read
[`.github/REPOGUARD.md`](.github/REPOGUARD.md) in full and follow it.

In short: preserve the existing architecture and working functionality;
do not re-engineer, redesign, or broadly refactor; do not change
authentication, RBAC, business logic, or the data layer without the
repository owner explicitly asking for that specific change; work on a
dedicated branch per milestone; keep diffs minimal and auditable; the
owner reviews and merges every PR.

If a request conflicts with RepoGuard, stop and say so rather than
resolving the conflict yourself.
